    Reading the plots

    • Each point is one sample. In the tissue panel, a grey line joins each patient's myometrium and leiomyoma.
    • TPM compares genes within a sample and samples within a dataset. Do not compare values across the three panels: tissue and cultured cells, different library preparations and read lengths.
    • DESeq2 statistics are computed within each dataset. log2FC is the first group relative to the second; padj is Benjamini–Hochberg over all genes tested in that comparison. A dash means the gene was removed by the expression filter (too few counts to test).
    • Brackets mark the DESeq2 comparisons: * padj < 0.05, ** < 0.01, *** < 0.001, ns not significant; hover a label for the exact value. LM vs MM pooled over genotype is in the table only.
    • The spheroid WT group has 2 replicates.
