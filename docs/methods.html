MED12 RNA-seq Explorer

Genes Comparisons Methods

All 40 samples were downloaded as raw reads and processed the same way, so the three datasets share one reference, one annotation and one quantification method. Every step is a script in the repository.

What the values mean

TPM

Transcripts per million, from Salmon, at the gene level. TPM corrects for sequencing depth and for gene length, so it compares genes with each other within a sample, and samples with each other within a dataset. It does not compare across the three datasets: tissue against cultured cells, different library preparations and read lengths, and the 2D library is unstranded. The Genes page plots TPM on a log scale by default (log2 of TPM + 1, with the ticks labelled in TPM) and never lets the axis top fall below 10 TPM.

Expression percentile

Where a gene's mean TPM in a group ranks among the 19,350 protein-coding genes with nonzero TPM in at least one sample (GENCODE gene_type). The 50th percentile is a typical gene; the 90th is in the top 10%.

log2FC and padj

From DESeq2, fitted separately in each dataset. log2FC is the first group relative to the second, so a positive value means higher in the first group. The site shows fold changes shrunken with apeglm, which pulls noisy estimates from low-count genes toward zero; the downloadable tables keep both the shrunken (log2FC_shrunk) and the unshrunken (log2FoldChange) values. padj is the Benjamini–Hochberg adjusted p-value from a Wald test. A gene was tested only if it had at least 10 counts in at least as many samples as the smallest group.

Differential expression design

DatasetDesignComparisons
Tissue~ patient + tissueLM vs MM, all 10 pairs
Tissue~ patient + group, group = MM, LM MED12 WT, LM MED12 mut LM mut vs MM; LM WT vs MM; LM mut vs LM WT
2D cells~ groupKO, Mut1, Mut2, each vs WT
3D spheroids~ groupMut1, Mut2, each vs WT

The patient term pairs each leiomyoma with its own myometrium, the multi-gene analogue of a paired t-test. Because every patient contributes a myometrium baseline, LM mut vs LM WT asks whether the leiomyoma-versus-myometrium change differs between MED12-mutant and wild-type tumours, although the two kinds of tumour come from different patients.

Caveats: the tissue comparisons by genotype use 6 mutant and 4 wild-type patients; the spheroid WT group has 2 replicates. No batch information (preparation or sequencing run) is recorded in GEO or SRA for any dataset. DESeq2 1.50.2, apeglm 1.32.0, R 4.5.2.

Processing

Reads

Runs were downloaded from NCBI SRA's AWS mirror and converted to FASTQ with sra-tools 3.0.3 (vdb-validate, then fasterq-dump --split-3). Every file was checked against the run's read count in SRA.

Reference

GRCh38 primary assembly with the GENCODE v44 comprehensive annotation (62,298 genes), the same GENCODE release as 10x Genomics' 2024-A reference but unfiltered.

Quantification

nf-core/rnaseq 3.27.0 (Nextflow 26.04.3, Docker), in Salmon-only mode: no genome alignment.

  • Quality control and trimming: FastQC 0.12.1, fastp 1.3.6.
  • Strandedness inferred per sample from a subsample of reads, then passed to Salmon.
  • Salmon 2.7.0 against a decoy-aware index: GENCODE v44 transcripts plus the whole genome as decoys, k = 31.
  • Transcript estimates summarized to genes with tximport (tximeta 1.20.1).

Reproducing

Every step is a script in github.com/brandonlukas/med12-tpm. Needs Nextflow ≥ 25.10.4, Docker, sra-tools, pigz, R with DESeq2 and apeglm, and Python with pandas.

./fetch_reference.sh            # GENCODE v44 fasta + GTF, md5-checked
./download_fastqs.sh 4          # 40 runs from SRA, read counts checked
./run_rnaseq.sh                 # nf-core/rnaseq (about 2 h on 44 cores)
python3 split_tpm.py            # per-dataset TPM tables
Rscript deseq2.R                # DESeq2 tables
python3 build_site_data.py      # data for this site
